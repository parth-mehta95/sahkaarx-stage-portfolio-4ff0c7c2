# Create Feature Branch and Open Pull Request

## Task Brief
Build on your initialized repo: create a feature branch, make meaningful commits, and open a PR for review.

## Scenario
Your team lead asks you to add a feature branch and submit a PR demonstrating professional Git workflow.

## Deliverables
- Feature branch with 2+ commits
- Pull request with description

## Success Criteria
- PR links to main branch
- Commit messages are clear
