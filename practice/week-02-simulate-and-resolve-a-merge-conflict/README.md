# Simulate and Resolve a Merge Conflict

## Task Brief
Intentionally create a merge conflict scenario in your repo and practice resolving it safely.

## Scenario
Your peer edited the same file on main; now your PR has a conflict. Resolve it and merge cleanly.

## Deliverables
- Resolved merge conflict
- Merged pull request

## Success Criteria
- Conflict markers removed
- Code is syntactically correct
